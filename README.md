# 🎓 Career AI — AI-Based Career Guidance Platform

**Career AI** is an AI-based career guidance platform designed to help students make informed career decisions based on their **personal interests, academic background, student inputs, and aptitude assessment results**.

The platform provides personalized career recommendations while maintaining secure user authentication and data management.

---

## 🚀 Features

* 🎯 **Personalized Career Recommendations** based on student inputs and aptitude assessments
* 📝 **Aptitude Assessment** to evaluate student interests and capabilities
* 🤖 **AI-Based Career Guidance** for personalized career suggestions
* 🔐 **Firebase Authentication** for secure user login and registration
* 📱 **Twilio OTP Verification** for account verification
* 👤 **User Data Management** for storing and managing student information
* 📊 Structured career recommendation logic based on assessment results

---

## 🧠 How It Works

```text
Student Registration
        ↓
Authentication & OTP Verification
        ↓
Student Information & Interests
        ↓
Aptitude Assessment
        ↓
Career Recommendation Logic
        ↓
Personalized Career Suggestions
```

The platform collects relevant information from students and combines it with aptitude assessment results to generate career recommendations suited to their profile.

---

## 🔐 Authentication

The platform implements secure user authentication using:

* **Firebase Authentication** for account registration and login
* **Twilio OTP verification** for phone-based account verification
* User information stored and managed using **MongoDB**

---

## 💡 Project Objective

Many students struggle to choose an appropriate career path because of limited awareness of available career options and uncertainty about their skills and interests.

**Career AI** aims to simplify this process by providing a structured platform where students can evaluate their aptitude and receive personalized career guidance.
